Key terms

layer
stack of neurons
activation (ReLU, softmax)
adds non-linearity
epoch
one pass over the data
loss
error being minimized
optimizer (Adam)
updates the weights

When to use DL

Shines on unstructured data (images, audio, text) with many examples. For tabular data, tree ensembles are usually better.
