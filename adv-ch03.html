groupby: split → apply → combine

groupby is the workhorse of pandas. It splits the table by a key, applies an aggregation to each group, and combines the results. It answers almost every 'what's the X per Y?' question.

In [ ]: python3
TIP The pattern df.groupby(key).agg(...) is worth memorizing — it's the single most common analysis move in pandas.

Lesson

Pivot tables

A pivot table reshapes grouped data into a grid — one variable down the rows, another across the columns. It's groupby in a spreadsheet-style layout.

Merging (joining) tables

Real data lives in multiple tables. merge joins them on a shared key — the same idea as a SQL join. Here we attach each region's manager from a second table.

In [ ]: python3
WHY IT MATTERS how= controls which rows survive: left keeps all left rows, inner keeps only matches, outer keeps everything. Choosing the wrong join is a common source of silently dropped rows.

Reshaping: wide ↔ long

Data comes in 'wide' form (a column per variable) or 'long' form (one row per observation). melt goes wide→long; pivot goes long→wide. Many tools expect one shape or the other.

In [ ]: python3

Lesson

Working with dates

Convert text to real datetimes with pd.to_datetime, then you can extract parts (month, weekday) and group by time. Time handling is essential for any real-world dataset.

Practice

EX 1

Revenue per rep

Using the sales table (available from the cells above), print the total revenue for each rep, as a plain dictionary sorted isn't required — just print the Series' values via .to_dict().

In [ ]: python3
Show solution

print(sales.groupby("rep")["revenue"].sum().to_dict())

EX 2

Count rows per region

Print how many rows belong to each region, as a dict. Expected: {'East': 3, 'West': 3}.

In [ ]: python3
Show solution

print(sales.groupby("region").size().to_dict())

EX 3

Highest-revenue product

Print the single product with the highest total revenue across all sales.

In [ ]: python3
Show solution

print(sales.groupby("product")["revenue"].sum().idxmax())
