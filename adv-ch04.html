Data cleaning & preparation

Real data is messy — wrong types, inconsistent text, outliers, and gaps. This chapter turns raw records into model-ready data: fixing types, standardizing text, handling outliers, encoding categories, scaling numbers, and avoiding the subtle trap of data leakage. Every cell runs live.

Handling missing values

Fill categorical gaps with a sensible placeholder or the most common value; fill numeric gaps with the mean or median. The right choice depends on the column and the model.

Detecting outliers with the IQR rule

An outlier is a value far outside the normal range. A common rule: anything beyond 1.5×IQR from the quartiles. Outliers can distort averages and models, so you flag them deliberately.

Lesson

Encoding categories & scaling numbers

Models need numbers, not text. One-hot encoding turns a category into 0/1 columns. And because features on wildly different scales (age vs salary) can bias many models, you scale them to a comparable range.

In [ ]: python3
LEAKAGE — READ THIS Data leakage is the deadliest cleaning mistake: computing scaling or fill values using the whole dataset — including your test set — leaks future information into training and inflates your scores. The fix: fit scalers and imputers on the training data only, then apply them to test data. scikit-learn Pipelines (Chapter 12) make this automatic.

EX 3

Min-max scale

Scale the x column to the 0–1 range and print the result rounded to 2 decimals as a list.

In [ ]: python3
Show solution

import pandas as pd d = pd.DataFrame({"x": [10, 20, 30, 50]}) s = d["x"] scaled = (s - s.min()) / (s.max() - s.min()) print(scaled.round(2).tolist())
