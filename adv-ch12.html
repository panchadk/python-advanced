Model validation & tuning

A single train/test split can mislead. This chapter covers the techniques that make your evaluation trustworthy — cross-validation, hyperparameter search, and pipelines that keep everything leak-free. These are what separate a reliable model from a lucky one. The first cell installs scikit-learn.

Lesson

Why one split isn't enough

A single train/test split gives one number — which depends on which rows happened to land in the test set. A lucky split flatters a model; an unlucky one punishes it. You need a more stable estimate.

Lesson

K-fold cross-validation

Cross-validation splits the data into k folds, trains on k-1 and tests on the held-out fold, k times — so every row is tested once. You report the mean and spread, a far more honest estimate of performance.

In [ ]: python3
TIP Report cross-validation as mean ± std. A high mean with a large std is less trustworthy than a slightly lower mean that's very stable across folds.

Lesson

Pipelines inside cross-validation

Notice we put the scaler inside the pipeline. That's essential: during cross-validation the scaler is re-fit on each training fold only, so no information leaks from the test fold. Scaling before CV would leak.

Lesson

Hyperparameter tuning with GridSearchCV

Models have knobs (hyperparameters) you set before training. GridSearchCV tries every combination you list, using cross-validation to score each, and reports the best — automatically.

In [ ]: python3
WHEN THE GRID IS HUGE For large search spaces, RandomizedSearchCV samples random combinations instead of trying all of them — far faster, and usually finds a near-best setting.

Lesson

The honest workflow

Put it together: a pipeline for preprocessing + model, cross-validation to estimate performance, and a search to tune hyperparameters — all without ever touching your final test set until the very end. This discipline is what makes results you can trust.

EX 1

Cross-validate a model

Run 5-fold cross-validation of a scaled logistic regression on the wine data and print the mean score rounded to 3 decimals.

In [ ]: python3
Show solution

from sklearn.datasets import load_wine from sklearn.linear_model import LogisticRegression from sklearn.preprocessing import StandardScaler from sklearn.pipeline import make_pipeline from sklearn.model_selection import cross_val_score X, y = load_wine(return_X_y=True) model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=5000)) print(round(cross_val_score(model, X, y, cv=5).mean(), 3))
