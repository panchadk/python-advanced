Visualization for insight

A good chart reveals what a table hides. This chapter covers matplotlib's structure and how to choose the right chart for the question. Charts render as images in a notebook or script; here we build figures live and inspect them, then you'll see exactly how to display or save them for real.

Setup: the figure / axes model

matplotlib draws onto an axes that lives inside a figure. You create both with plt.subplots(), then call plotting methods on the axes. Install it first (a few seconds).

Lesson

Choosing the right chart

The chart follows the question: a line shows change over time; a bar compares categories; a histogram shows the distribution of one variable; a scatter shows the relationship between two.

In [ ]: python3
TIP Match the chart to the data type: categories → bar; one numeric variable → histogram; two numeric variables → scatter; a value over time → line. Picking the wrong chart hides the very thing you're trying to show.

Lesson

Small multiples & subplots

Sometimes one chart isn't enough. plt.subplots(rows, cols) gives you a grid of axes so you can compare several views side by side.

Lesson

seaborn for statistical charts

seaborn builds on matplotlib with attractive statistical plots in one line — histograms, box plots, correlation heatmaps. In a notebook you'd call e.g. sns.histplot(df["income"]). The idea: seaborn for quick statistical views, matplotlib when you need fine control.

In [ ]: python3
IN THE REAL WORLD In a Jupyter notebook or a .py script you finish with plt.show() to display the chart, or fig.savefig("chart.png", dpi=150, bbox_inches="tight") to save it as an image. The build-then-render split is the same everywhere.

Title a chart

Create a figure, plot the values [5, 10, 15], set the title to Revenue, and print the title back to confirm.

In [ ]: python3
Show solution

fig, ax = plt.subplots() ax.plot([5, 10, 15]) ax.set_title("Revenue") print(ax.get_title())
