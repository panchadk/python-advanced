Exploratory data analysis

First look, summaries, distributions, correlation

First look

df.shape df.head()
size & sample
df.columns.tolist()
column names

Summaries

df.describe()
count/mean/std/quartiles
s.mean() s.median() s.std()
central tendency & spread
s.min(), s.max()
range

Correlation

df.corr()
full matrix (-1..1)
df.a.corr(df.b)
one pair

Group comparison

df.groupby('g')[['a','b']].mean()
metric per group

Sanity checks

df.isna().sum()
missing values
df.duplicated().sum()
duplicate rows
Reading skew

If mean >> median, data is right-skewed (a few big values). Correlation is not causation.

EDA mindset

Stay curious: look, ask 'does this make sense?', and follow the surprises before modeling.
