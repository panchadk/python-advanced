The full end-to-end ML workflow

1. Ingest

load / read_csv
check shape & class balance

2. Explore

df.describe()
feature scales, missing, balance

3. Prepare (pipeline)

make_pipeline( StandardScaler(), RandomForestClassifier(...))

4. Validate

cross_val_score(pipe, X_train, y_train, cv=5)
before touching test

5. Evaluate

pipe.fit(X_train, y_train)
accuracy_score / recall_score
confusion_matrix(y_test, pred)

6. Persist

import pickle
pickle.dumps(pipe)
save model+scaler together
pickle.loads(blob)
reload & predict
The lifecycle

Ingest -> explore -> prepare -> validate -> evaluate -> persist. Every ML project is a variation on this.
